# 真实定位到点语音导览设计

## 目标

把游客端链路补成可验证的“真实定位 -> 景点围栏 -> 数字人自动播报”，并保留比赛现场可复现的演示定位模式。

系统对真实定位采用严格准入条件：只有浏览器上报的 `accuracy <= 10m` 时才允许自动播报。这个条件代表设备定位报告精度，不承诺手机在任何环境下的物理位置误差都小于 10 米。精度不足时不自动播报，界面显示原因并允许游客继续使用手动导览。

## 方案选择

采用导入阶段高德地理编码、运行时本地围栏判断的混合方案：

1. 使用高德 Web 服务 API 一次性查询景点的游客入口或主要观景点。
2. 人工核对返回的地址和 `location`，将经纬度写入坐标校准文件和演示数据库。
3. 游客端使用高精度浏览器定位持续获取位置，不在每次定位时调用高德地理编码。
4. 将浏览器返回的 WGS84 坐标转换为与高德数据一致的 GCJ-02 坐标。
5. 通过连续定位样本和 Haversine 距离判断是否进入景点围栏。

不采用运行时地理编码，因为它会增加网络依赖、接口限流风险和服务端密钥管理复杂度。高德地图 JS Key 与高德 Web 服务 Key 分开配置，Web 服务 Key 只允许在导入命令或服务端使用。

## 数据与坐标

现有 `ScenicSpot` 已具备 `Latitude`、`Longitude`、`Location`、`GeofenceEnabled`、`GeofenceRadiusM`、`GeofenceIntroText` 和 `GeofenceCooldownMinutes` 字段，继续复用，不新增重复字段。

坐标校准数据至少覆盖：灵山大佛、九龙灌浴、灵山梵宫、五印坛城、文创驿站。每条数据包含景点名称、查询地址、返回地址、经度、纬度、坐标系、来源和核验时间。坐标必须是游客可接近的入口或主要观景点，不使用无法到达的建筑中心点。

校准命令读取 `AMAP_API_KEY` 和可选的 `AMAP_SECURITY_CODE`，禁止把 Key 写入源码、JSON、前端构建产物或提交记录。高德接口失败、返回空结果、坐标越界或名称匹配不确定时，命令失败并不覆盖已有坐标。

## 真实定位链路

游客点击“开启到点讲解”后：

1. 检查浏览器是否支持定位，并请求权限。
2. 使用 `watchPosition`，开启高精度模式，设置合理的超时和缓存时间。
3. 记录位置、设备上报精度和时间戳。
4. 丢弃 `accuracy > 10m` 的样本，不触发播报。
5. 对最近的有限数量样本做中位数或稳定窗口判断，降低单次漂移造成的误触发。
6. 对每个启用围栏的景点计算距离；距离小于该景点半径且精度合格时触发最近景点。
7. 写入页面生命周期和 localStorage 冷却记录，避免反复播报。
8. 将景点讲解词交给现有数字人消息和 TTS 链路。

围栏半径仍由景点配置决定，默认值不能被解释为定位精度。大佛广场、演出场地等开放区域可以使用更大的触发半径，但只有定位精度合格才触发。室内、树荫、建筑遮挡和系统关闭后台定位时，系统显示“定位精度不足/定位不可用”，不伪造已到达状态。

## 演示定位

数字人页面增加真实定位状态和演示定位入口。演示定位从已加载的景点坐标生成位置样本，并调用与真实 GPS 完全相同的围栏判断和播报流程；它只用于比赛电脑端复现，不改变生产真实定位逻辑。界面明确区分“真实 GPS”和“演示定位”，避免把模拟数据误认为游客实际位置。

音频未解锁时，进入围栏不能消耗景点的触发机会。游客完成声音授权后，系统可以立即重试最近一次合格定位；播报中断时不重复创建同一段语音队列。

## 错误与边界

- 浏览器不支持定位：保留地图、二维码和手动讲解，显示不支持原因。
- 用户拒绝权限：不循环弹窗，提供重新开启入口。
- 定位超时或不可用：保留最后一次状态，不触发自动播报。
- `accuracy > 10m`：显示精度数值和等待状态，不自动播报。
- 坐标为零、越界或坐标系缺失：该景点不参与围栏判断。
- 高德校准失败：不覆盖已有有效坐标，并让 seed 命令返回失败。
- 进入多个围栏：只触发距离最近且满足条件的景点。
- 重新进入景点：遵守景点冷却时间，默认 24 小时或景点配置值。

## 测试与验收

后端测试覆盖高德响应解析、坐标合法性和 seed 写入字段。前端测试覆盖：WGS84/GCJ-02 转换、`accuracy` 门槛、距离边界、连续样本、冷却、景点数据晚于定位加载和演示定位触发。

浏览器验收覆盖：

- 开启真实定位后显示权限和精度状态。
- 精度大于 10 米时不播报。
- 演示定位到某景点后自动出现讲解消息并调用 TTS。
- 同一景点在冷却期内不重复播报。
- 关闭自动导览后停止定位监听。
- 定位失败和声音未授权时页面不报错、不误报已播报。
