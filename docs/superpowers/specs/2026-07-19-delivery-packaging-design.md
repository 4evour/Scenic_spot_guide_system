# 答辩交付包设计

## 目标

生成三类可直接交付的最新成果，并尽量将每个压缩包控制在 1GB 内：

1. Windows 可执行演示包；
2. 作品源码包；
3. 最新作品说明书（DOCX 与同内容 PDF）。

## 可执行演示包

面向 Windows x64。包含预编译的 Go 主程序与演示数据初始化程序、Vue 构建产物、知识库、配置、真实 Live2D Core/模型、Open-LLM-VTuber 源码、锁文件和便携 `uv.exe`。

一键启动器负责：

1. 检查网络、磁盘和核心资源；
2. 首次运行用 `uv sync` 安装 Python 运行环境；
3. Open-LLM-VTuber 首次启动时下载约 1.12GB SenseVoice ASR 模型；
4. 生成仅用于当前进程的 JWT Secret，启用本机演示模式；
5. 初始化确定性演示数据；
6. 启动 Go 服务与 Open-LLM-VTuber，并打开统一登录入口。

压缩包不包含 `.venv` 和 ASR 模型，因此包体小于完整离线包；首次启动需要联网并预留约 3GB 磁盘空间。

## 源码包

源码包同时保留 `scenic-guide/` 与 `Open-LLM-VTuber/`。包含当前源码、依赖锁文件、前端构建产物、Live2D Core/模型、知识库、测试、文档、示例配置和打包脚本。

排除 `.git`、`.venv`、`node_modules`、ASR 大模型、本机数据库、`.env`/`.env.local`、缓存、日志、聊天历史、测试输出和临时文件。源码包不得包含真实 API Key、Token、密码或本机连接串。

## Key 与功能边界

- 默认不配置外部大模型 Key，系统使用本地 BM25、Light-Rerank 和本地证据生成，文字问答仍可运行。
- 外部 Chat Key 只用于增强语言自然度、复杂归纳和多轮对话；评委可在本机按说明自行配置。
- Embedding Key 是可选项，用于语义检索与混合检索；缺失时回退本地检索。
- Edge TTS 不需要大模型 Key，但需要联网访问在线语音服务。
- SenseVoice ASR 不需要 Key，首次运行下载后可在本地识别语音。
- 任何真实 Key 均不得写入源码、压缩包、日志或作品说明书。

## RAG 评测口径

最终 50 题真实语料回归使用 `generation_provider=local`、`retrieval_mode=bm25-local`，未调用外部大模型：50/50 通过，关键词覆盖率 100%，Recall@8 100%，MRR@8 约 0.953。纯检索版本关闭生成后也为 50/50。

该结果证明固定真实语料集上的本地事实问答和召回稳定，不代表任意开放问题均能 100% 回答。无外部大模型时，复杂开放问答、多轮上下文归纳和语言自然度会下降，但已覆盖的景区事实不会因为缺少 Key 而整体失效。

## 作品说明书

作品说明书包含：项目背景、系统架构、技术栈、核心功能、数字人链路、演示数据、详细配置流程、首次启动流程、外部大模型/Embedding 配置、无 Key 降级矩阵、RAG 评测口径、测试结果、打包内容、授权边界和常见问题。

DOCX 使用正式报告版式并提供 PDF 阅读版。文档不得包含真实凭据或夸大评测结论。

## 验收

- 两个压缩包均小于 1GB，能正常解压且不存在路径穿越或重复嵌套目录。
- 可执行包包含一键启动器、预编译程序、便携 uv、Live2D 资源和无 Key 配置说明。
- 源码包包含两个项目且排除开发缓存、ASR 模型、虚拟环境和秘密文件。
- 对压缩包清单和解压目录运行秘密扫描。
- DOCX 通过 Office OpenXML 校验、内容/结构/版式检查，PDF 能正常打开。
