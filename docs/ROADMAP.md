# Scenic Guide 路线图 (Roadmap)

> 最后更新: 2026-06-18
> 基于当前代码实现和开源项目竞争调研维护

## 调研背景

调研了 GitHub/Gitee 上与景区导览相关的开源项目，与 scenic-guide 对比分析后制定本路线图。

核心参考项目:
- [TripStar](https://github.com/1sdv/TripStar) — ⭐1,800+ AI 多智能体旅行规划
- [WeTravel](https://github.com/nanbouking/WeTravel) — ⭐265 微信小程序景区平台，仅作预约/运营形态参考，不采用小程序端
- [TravelGuide3D](https://github.com/kiranbaby14/Travel-Guide-3D) — 3D 电影级路线可视化
- [CyberVerse](https://github.com/Lynpoint/CyberVerse) — 实时数字人交互参考

## 短期计划 (P0/P1)

| # | 任务 | 优先级 | 现状 | 目标 |
|---|------|--------|------|------|
| 1 | **实时数字人链路完善** | P0 | 已有 SSE 问答、`/vtuber-ws/*` 代理、流式 TTS、打断和口型驱动 | 稳定现有链路，补齐打断、错误提示、会话落库和监控 |
| 2 | **游客账号 + 会话记忆** | P0 | 已有游客登录、正式账号、会话列表/消息接口；游客升级为同一账号原地转正，升级前会话保留 | 完善跨访问历史和会话搜索体验 |
| 3 | **地图体验优化** | P1 | 已有游客地图、结构化点位、路线和服务提醒兜底数据 | 景点图片、标注细化、真实数据优先和离线兜底一致 |
| 4 | **多语言 i18n** | P1 | ✅ 中/英 locale 与后端语言中间件 | 持续补齐新增页面和错误文案 |
| 5 | **GPS 定位主动导览** | P1 | 已有电子围栏字段、游客端自动讲解开关 | 继续验证定位授权、冷却策略和移动端体验 |
| 6 | **运营闭环完善** | P1 | 已有游客反馈、AI 分析、知识候选、游客问题处理和二维码管理 | 完善审核流程、报告可信数据源和演示数据边界 |

## 长期计划 (P2)

| # | 任务 | 备注 |
|---|------|------|
| 7 | **预约订阅板块** | 独立票务系统，体量大需单独立项 |
| 8 | **部署验证与运维补强** | Docker Compose 已存在，后续补健康检查、日志、监控和发布说明 |

## 不做

- 多 Agent 架构: 当前单 Agent + RAG 已足够
- 知识图谱可视化: 非刚需
- 离线模式: 以联网场景为主
- 微信小程序端: 小程序环境无法完整承载当前 Live2D、麦克风、WebSocket、流式 TTS 和数字人打断链路；项目主端保持 Web/Vue
