## 评估方法

### 端到端评估
- 测试集：25 题，覆盖 6 类问题
- 评估方式：调用 `/api/v1/ai/chat` API，检查回答是否包含期望关键词
- 关键词匹配：任一关键词匹配即通过（OR 逻辑）
- 脚本：`scripts/e2e_eval.js`

### 检索评估
- 测试集：203 条真实资料问答对
- 评估方式：`cmd/rag-eval` CLI 工具
- 指标：通过率、Recall@K、MRR@K、关键词覆盖率
- 模式：light-rerank（BM25 + 可解释重排）

## 结论

1. **端到端准确率 100%**：所有 25 题均通过，满足赛题"准确率不低于90%"的要求
2. **检索准确率 93.6%**：203 条真实资料集，light-rerank 模式
3. **边界问题处理良好**：门票、宠物、无人机等边界问题均能正确引导游客查看官方信息
4. **个性化推荐有效**：亲子路线、历史路线等个性化推荐准确
